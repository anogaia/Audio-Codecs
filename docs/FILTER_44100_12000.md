# 44.1 kHz ↔ 12 kHz polyphase FIR

## Why this filter exists

The existing [`AudioCodecFilter_4X_PolyphaseFIR`](../Codecs/Filters/AudioCodecFilter_4X_PolyphaseFIR.hpp) is an **integer 4:1** design for **48 kHz ↔ 12 kHz**. ccChat and other VOIP paths also need **44.1 kHz** PCM while keeping the compressed domain at **12 kHz**.

Exact ratio:

```text
12000 / 44100 = 40 / 147
```

So this filter is a **rational polyphase** resampler (interp 40 / decimate 147 on encode; reverse on decode), not another 4:1.

## Why not 4:1 + Gaussian 11.025↔12

A tempting shortcut is:

1. Reuse the 4:1 FIR → **11.025 kHz**
2. Cheap 3-tap Gaussian (or similar) to nudge **11.025 ↔ 12**

That can work as a quick A/B experiment because the hard anti-alias is already done, and the second stage only moves rate by ~8.8%. It is **not** the primary path here because:

- A short Gaussian still costs passband droop near ~5 kHz (the band the long FIR paid for), twice on a round trip
- You still need correct **160:147** timing/state for the second stage
- Cascading two filters stacks ripple/droop versus one Parks–McClellan prototype aimed at 12 kHz

## Design procedure

Same absolute specs as the 48 kHz comments:

| Spec | Value |
|------|--------|
| Method | Parks–McClellan (`scipy.signal.remez`) |
| Passband edge | 5500 Hz |
| Stopband edge | 6500 Hz (`12000 − 5500`) |
| Stopband atten | ≥ 65 dB (measured ~67.4 dB) |
| Passband deviation | ~0.05 dB on the selected design |

Prototype is designed at the common intermediate rate:

```text
40 × 44100 = 147 × 12000 = 1 764 000 Hz
```

Tap count **5880** = `lcm(40, 147)` so both polyphase banks are even:

- Encode: 40 phases × 147 taps
- Decode: 147 phases × 40 taps (coeffs pre-scaled by `147/40` for interpolator gain)

`getDecimatedSamples` / `getExpandedSamples` are **state-aware** (remainder across packets). Do not size buffers with a bare `n * 40 / 147` if the filter instance is reused across blocks.

## Regenerate coefficients

```bash
cd Audio-Codecs
python3 -m venv tools/.venv
source tools/.venv/bin/activate
pip install scipy numpy
python tools/design_fir_44k1_12k.py --emit-header
```

To force the checked-in design:

```bash
python tools/design_fir_44k1_12k.py --n 5880 --stop-weight 10 --emit-header
```

## Tests

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target test_filter_44100_12000
./build/test_filter_44100_12000
# or: ctest --test-dir build -R Filter44100To12000 --output-on-failure
```

Checks long-run rate ratio, exact `147↔40` blocks, and a 1 kHz round-trip RMSE smoke test.
